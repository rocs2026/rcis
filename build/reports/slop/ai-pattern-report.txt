## How the score works

- Five categories are scored 0-20 each; a file can score at most 100.
- Explicit AI markers (`Generated by ChatGPT`, `Generated with Claude Code`, `Co-authored-by: Copilot`, `@author Gemini`, ...) score 20 on their own.
- Generated test style is scored too: the same PHPDoc sentence repeated across many methods, PHPDoc on every field and test method, and sentence-length test names.
- Exception handlers that only print to the console also score, as does dynamic SQL in repository code.
- The check fails when the aggregate score or any single file reaches the threshold.
- Comments and string literals are stripped before declaration and structure rules run; getters/setters are excluded from duplication checks.
- To exclude a generated file, add `@generated` or `// ai-detect:ignore` to it.
